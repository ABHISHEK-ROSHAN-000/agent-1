# Models.dev catalog snapshot

`models-dev.json` is a pinned snapshot of the OpenRouter, OpenAI, and LM Studio
entries from https://models.dev/api.json, generated on 2026-11-10.

Agent-1 normalizes the snapshot into its own provider/model tables. The snapshot
provides a pinned offline model catalog without requiring network
access at startup. Provider credentials are never stored in this file.

Source: https://github.com/sst/models.dev (MIT). See `THIRD_PARTY_NOTICES.md`.
